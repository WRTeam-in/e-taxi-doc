# How to Change Images in App

All app images are SVG files inside the `assets/images/` folder, grouped by feature (for example `brand/`, `vehicles/`, `onboarding/`, `payment/`).

To change an image, replace the existing file with your own **SVG** image using the **same file name and folder**.
