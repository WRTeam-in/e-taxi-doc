# How to Change Splash Screen Image in App

The splash logo is an SVG file. Replace it with your own SVG logo using the **same file name**:

- **Customer app:** `assets/images/brand/splash_image.svg`
- **Driver app:** `assets/images/brand/splash.svg`

![Splash Screen](/images/app/splash_screen.png)

## Native Launch Screen

The native launch screen (shown while the app is loading) uses the app launcher icon and brand background color in both apps. Once you change the app logo (see [Change App Logo](./change-app-logo.md)), the launch screen is updated as well. No separate splash generation is needed.
